# LUH TV — обновления

Здесь опубликованы APK для **LUH TV**, **2SUB TV Client** и **SmartTube**, а также файл версий для экрана «Обновления» в лаунчере.

На приставке с LUH TV 1.58 и новее новые версии можно проверять и устанавливать в верхнем меню **Обновления**. Если установлена более старая версия и прежний сервер недоступен, установите APK LUH TV 1.58 по ссылке выше поверх текущей версии. Данные лаунчера сохраняются, поскольку пакет и подпись прежние. Android попросит подтвердить установку.

## Что изменилось

- **LUH TV 1.58:** кнопка VPN управляет профилем AmneziaWG; обновления перенесены на GitHub.
- **2SUB TV 2.37-beta7:** кнопки пульта для русских субтитров и курсора, прокрутка у края экрана, перемотка на основном таймлайне и выбор следующей серии.
- **SmartTube 32.68:** официальный APK SmartTube Stable, добавленный в каталог обновлений.

Полная история записанных изменений: [CHANGELOG.md](CHANGELOG.md). Запись в истории не означает, что APK каждой промежуточной или тестовой версии сохранён в этом репозитории. Для установки используйте ссылки текущего релиза.

## Как работают обновления

Лаунчер читает [updates.json](updates.json) через HTTPS, скачивает выбранный APK и проверяет его SHA-256, имя пакета и версию перед передачей системному установщику Android. Резервный адрес файла версий находится на `raw.githubusercontent.com`. Файл содержит только публичные ссылки и сведения о версиях.

Исходный код и ключ подписи в этом репозитории не публикуются. SmartTube — отдельное приложение; его [официальный проект](https://github.com/yuliskov/SmartTube).
